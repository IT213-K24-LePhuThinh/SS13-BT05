---------------------------------------------------------------------
 RANH GIỚI THÀNH PHẦN
---------------------------------------------------------------------
  API Client        : ngoài cùng, gửi request kích hoạt agent.
  Spring AI ChatClient: lõi điều phối tool call, vòng lặp agent.
  Postgres MCP Server: đối soát dữ liệu vận chuyển (giao thức MCP stdio).
  FileSystem MCP     : đọc log, ghi báo cáo.
  Custom Archive Tool: nén log cũ, giải phóng dung lượng.
  Langfuse Gateway   : thu nhận trace/span/metrics qua OTLP.
